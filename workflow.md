## 10. Quick Reference

```
New project:
  Brainstorm → plan.md → choose stack → backlog → issues → generate kit → run loop

Existing project:
  Brainstorm → plan-<feature>.md → review approach → backlog → issues → update kit → run loop

Per issue:
  PM grooms → Engineer implements → QA verifies → PASS/FAIL loop → close

Investigation:
  Define question → Search & trace → Impact report → Decide → (feed into build if needed)

Small task:
  Clear prompt with AC → implement → test → done
```
